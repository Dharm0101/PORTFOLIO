# PORTFOLIO

> Modern, interactive developer portfolio for **Dharm Mendpara** — AI & Machine Learning Engineer & Full Stack Developer. Built with React, Vite, and Vanilla CSS.

## 🚀 Featured Projects
- **[TEE VERSE](https://tee-verse-mu.vercel.app/)** — Heavyweight Streetwear & Graphic Tees E-Commerce Platform.
- **[DriveHub](https://drive-rental-mu.vercel.app/)** — Smart Vehicle Rental Marketplace for cars, SUVs, luxury vehicles, and bikes across 50+ cities.
- **[Brahmani Textile Billing System](https://github.com/dharm-mendpara/brahmani-textile-billing)** — Enterprise GST invoicing and fabric roll inventory management ERP.

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite, Vanilla CSS (Design Tokens, Glassmorphism, Responsive Grid)
- **Icons**: Lucide React
- **Features**: Dynamic Theme Switching, Interactive Terminal Mode, Architecture Inspection Modals, Smooth Navigation

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
